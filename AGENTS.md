# AGENTS.md — постоянные инструкции для агентов

Semantic TextNavigator — прототип для специалиста по закупкам. По загруженным TXT-документам он показывает сумму и срок поставки, действующие на дату проверки, с точными цитатами и переходом к исходным абзацам.

## Источники истины

| Файл | Назначение | Правка |
|---|---|---|
| `docs/TASK.md` | исходное задание | не менять |
| `docs/PRD.md` | продуктовые требования | только по согласованию |
| `docs/ARCHITECTURE.md` | поток данных, модули, модель, правила извлечения и статусов, решения и компромиссы, ограничения | при изменении кода или решений |
| `docs/PLAN.md` | итерации, критерии, матрица «критерий → тест», журнал ИИ-разработки | каждую итерацию |
| `README.md` | краткая записка (не более двух страниц): демо и запуск, ответы на 4 вопроса, для кого, вопросы клиенту, допущения, метрики, архитектура, три ключевых решения, масштабирование, улучшения | только по существу, объём не растёт |
| `VIBECODING_REPORT.md` | отчёт о разработке с ИИ | при значимых событиях: деплой, крупная переделка, новые ошибки ИИ |
| `old_README.md` | архивная подробная версия README | не менять |

## Жёсткие ограничения

1. Нет LLM, внешних и платных API в runtime. Извлечение — regex и контекстные правила, разрешение — детерминированная логика.
2. Никакого хардкода из `documents/`: номера договоров, суммы, даты, поставщики и имена файлов не появляются в `textnav/` и `app.py`. В тестах использовать их можно. Проверяется `tests/test_no_hardcode.py`.
3. Не придумывать значения. Если надёжного значения нет — `NO_DATA` или `NEEDS_REVIEW` с причиной и цитатой.
4. У каждого показанного значения есть `Citation`, и выполняется инвариант `text[start:end] == quote`.
5. Результат зависит только от содержимого файлов и даты проверки, а не от имён файлов и порядка загрузки.
6. Ядро (`textnav/` кроме `textnav/ui/`) не импортирует streamlit.
7. Новое извлекаемое поле — это новый `FieldSpec` в реестре `textnav/terms.py`. Движок и резолвер при этом не меняются.
8. Не добавлять зависимости и абстракции без конкретной необходимости. Новая зависимость появляется только после согласования и с пином в `requirements*.txt`.

## Процесс

- Работа идёт итерациями из `docs/PLAN.md`. Следующая итерация не начинается, пока не закрыта текущая.
- TDD: сначала падающий тест, затем код. Для правил извлечения тест — это сниппет текста с ожидаемым результатом, включая дистракторы и вариации формулировок.
- **Definition of Done итерации:**
  - `.venv/bin/pytest` и `.venv/bin/ruff check .` зелёные, код отформатирован (`ruff format`);
  - критерии итерации в `docs/PLAN.md` выполнены, статус обновлён;
  - затронутые документы обновлены (см. матрицу);
  - в журнал ИИ-разработки (`docs/PLAN.md`) добавлена строка.
- Изменения интерфейса дополнительно проверяются в браузере (`STN_PRELOAD_DIR=documents .venv/bin/streamlit run app.py`), в том числе на мобильной ширине: AppTest не видит вёрстку и не умеет загружать файлы.
- После проверенной итерации делаются коммит(ы) и `git push origin main`.
- Команды запуска и тестов — в начале `README.md`, окружение — в разделе «Окружение» ниже.

## Соглашения

- Код, идентификаторы, комментарии, docstrings и сообщения коммитов пишутся на английском. Формат коммитов — Conventional Commits: `feat:`, `fix:`, `test:`, `docs:`, `chore:`, `refactor:`.
- `AGENTS.md`, `docs/*`, `README.md` и тексты UI пишутся на русском.
- Python 3.12. Зависимости фиксируются пинами: runtime в `requirements.txt`, dev в `requirements-dev.txt`. Раскладка плоская: пакет `textnav/` лежит в корне.
- Примеры в комментариях и docstrings — нейтральные значения, не из `documents/`. Неразрывный пробел и BOM в исходниках записываются только escape-последовательностями (`\u00a0`). Оба правила проверяет `tests/test_no_hardcode.py`.
- Текст загруженных документов — недоверенный ввод: в HTML он попадает только через `html.escape`, в Markdown — через экранирование.

## Окружение

- Установка: `python3.12 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt`.
- Обновление пинов: в чистом venv на Python 3.12 установить нужную версию `streamlit` и заменить тело `requirements.txt` выводом `pip freeze`, сохранив комментарий-шапку; затем проверить установку из чистого клона.
- Streamlit Community Cloud: приложение https://stereos-textnavigator.streamlit.app обновляется само при push в `main`. Python выбирается только при создании приложения: доступны 3.11–3.14, по умолчанию 3.14 — нужен 3.12. Сменить версию можно только пересозданием приложения.

## Что обновлять при изменениях

| Изменение | Документ |
|---|---|
| правила извлечения, статусы, модель данных, состав модулей | `docs/ARCHITECTURE.md` |
| продуктовое решение, компромисс, ограничение | `docs/ARCHITECTURE.md`, разделы «Решения и компромиссы» и «Ограничения и заглушки»; в `README.md` — только если меняются три ключевых решения |
| статус итерации, тест к критерию, журнал ИИ | `docs/PLAN.md` |
| зависимости, окружение, деплой | раздел «Окружение» этого файла; команды запуска — начало `README.md` |
